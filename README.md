# Full Court Stickman

macOS 13 이상에서 실행하는 2D 농구 슛 연습 앱입니다. Apple Silicon과 Intel을 지원합니다.
사진 얼굴 + 졸라맨 캐릭터, 나무 코트, 키보드 이동과 드리블·슛·점프·덩크·수비 애니메이션을 포함합니다.
현재는 싱글 플레이 연습 모드이며 상대 AI/온라인 대전은 없습니다.

버전 0.2.0에는 8방향 이동 시 정면·좌우·뒷모습 머리 전환이 추가되었습니다.
대각선 각도는 가까운 방향의 사진을 사용하며 실제 3D 회전은 아닙니다.
점프·점프슛·블로킹 전환은 관절 위치를 보간하며 체공 궤적을 다시 시작하지 않습니다.
Shift 달리기, 0.9초 점프와 부드러운 공중 동작 전환을 포함합니다.

## 설치

GitHub 릴리스와 Homebrew cask가 공개되어 있습니다.

```sh
brew tap sonsy12/bk
brew install --cask full-court-stickman
```

응용 프로그램 폴더의 **Full Court Stickman**을 실행하세요.

## 조작

| 키 | 동작 |
|---|---|
| 방향키 | 이동; 공 가까이 가면 자동 획득 |
| Shift + 방향키 | 달리기 (이동 속도 1.6배, 모습·애니메이션 동일) |
| Space | 독립 점프 (약 0.9초, 높이는 기존과 동일) |
| X | 누르고 게이지를 조절한 뒤 놓아 슛; 점프 중에는 점프슛 |
| Z | 골대 가까이에서 공을 들고 덩크 |
| C | 누르는 동안 수비; 점프 중 누르면 블로킹 |
| R | 점수와 공 초기화 |
| Command-Q | 종료 |

공을 소유하면 자동으로 드리블합니다. 득점한 경우에만 공이 가운데로 돌아오며,
실패한 슛은 코트에 남아 다시 잡을 수 있습니다. 조준 화살표와 대상 골대가 초록색이면 링 안쪽을 겨냥한 상태입니다. 이 상태에서 초록 게이지 구간에 맞춰 X를 놓으면 성공 궤적으로 날아갑니다. 조준이 벗어나면 주황색 화살표로 알려줍니다. 초록 구간은 가까운 거리(200 이하) 32%, 중간 거리(450) 16%, 먼 거리(650 이상) 6%이며 그 사이는 연속적으로 좁아집니다. 표시 막대는 1.1초마다 왕복합니다.
슛은 발사 순간 바라보는 방향을 기준으로 날아갑니다. v0.3.1부터 전방 ±22.5도 안의 골대는 초기 슛 방향을 링 중앙으로 보정합니다. 초록 조준 화살표는 보정 후 실제 발사 방향을 보여줍니다. 골대를 등지거나 보정 범위를 벗어나면 바라보는 8방향 그대로 쏘며, 발사 후에는 공을 유도하지 않습니다. 타이밍을 놓친 짧은·긴 슛은 그대로 실패 궤적으로 남습니다.
빗나간 공은 바닥에서 감쇠하며 튕긴 뒤 멈추고, 낮게 튀는 동안에도 리바운드로 잡을 수 있습니다.
림과 백보드에는 공의 높이를 포함한 충돌·반사 처리가 적용됩니다. 링 가운데 빈 공간은 충돌 대상이 아닙니다.
v0.3.2부터 일반슛·점프슛은 릴리스 순간 초록 타이밍 성공과 실제 링 하향 통과를 모두 충족해야 득점합니다. 타이밍 결과는 발사 때 고정됩니다. 초록 구간을 벗어난 슛은 림·백보드 반사로 우연히 들어가려 해도 실패로 튕겨 나오며, 중앙으로 초기화하지 않습니다. 초록 타이밍에 성공한 공은 반사 후 실제 링을 통과해도 득점합니다. 가까운 골대를 바라보고 하는 Z 덩크는 게이지 조건에서 제외합니다. 골이 나면 짧은 네트 통과 표시 후 중앙으로 공이 돌아옵니다.
빠른 타이밍은 짧은 슛, 늦은 타이밍은 긴 슛으로 표현합니다. 거리별로 비행 시간이 달라집니다.
배경의 흰 3점선에 맞춘 금색 점선과 같은 경계를 판정에 사용합니다. 두 발이 모두 선 밖이면 3점, 선을 밟거나 안쪽이면 2점입니다. 점프슛은 도약 직전 발 위치를 사용합니다. 실제 경기장 공식 치수가 아닌 이 코트에 맞춘 아케이드 규칙입니다.

## 자동 업데이트

실행 시 GitHub 최신 릴리스를 확인합니다. Homebrew로 설치된 앱이면 새 버전을
Homebrew의 체크섬 검증 경로로 자동 설치합니다. 현재 플레이를 종료시키지는 않으며,
앱을 다시 열면 새 버전이 적용됩니다. 네트워크/업데이트 실패 시 기존 앱은 그대로 사용 가능합니다.
직접 압축 파일을 내려받은 앱은 자동 설치 대상이 아닙니다.

```sh
brew update
brew upgrade --cask sonsy12/bk/full-court-stickman
```

## 개발 및 배포

```sh
bash scripts/build.sh
open "build/Full Court Stickman.app"
```

`dist/Full-Court-Stickman.zip`에 universal 앱이 생성됩니다.
실행 파일은 임시(ad-hoc) 서명이며 Apple 공증은 아직 지원하지 않습니다.
다운로드 앱이 차단되면 시스템 설정 → 개인정보 보호 및 보안의 ‘확인 없이 열기’를 사용하세요.
Gatekeeper를 전체 비활성화할 필요는 없습니다.

다음 릴리스는 Info.plist의 버전을 올리고 빌드한 뒤 GitHub 릴리스에 ZIP을 업로드하고,
Homebrew cask의 버전과 SHA256을 같은 릴리스에 맞춰 갱신해야 합니다.
캐릭터에 사용된 사진의 권리는 원 권리자에게 있으며, 별도의 재배포 허락을 부여하지 않습니다.
