# Full Court Stickman

현재 소스는 **0.5.0-beta.5 LAN 리뷰 빌드**입니다. 슛 동작과 연결된 단방향 X 게이지, C 손 올림 수비, B 독립 스틸, V 점프 블록을 적용했습니다. 거리뿐 아니라 이동과 실제 수비 견제가 초록 구간에 반영됩니다. 경기 규칙 버전이 바뀌어 두 맥북 모두 새 베타로 업데이트해야 합니다. 안정 버전은 v0.4.0이며, 두 실제 맥북에서의 Wi-Fi 검증 전까지 자동으로 안정 버전을 대체하지 않습니다. [기획서 비교·구현 현황·남은 작업과 두 맥북 테스트 절차](docs/lan-plan-comparison.md)를 참고하세요.

macOS 13 이상에서 실행하는 2D 농구 연습 앱입니다. Apple Silicon과 Intel을 지원합니다.
사진 얼굴 + 졸라맨 캐릭터, 나무 코트, 키보드 이동과 드리블·슛·점프·덩크·수비 애니메이션을 포함합니다.
슛 연습과 상대 AI가 있는 수비 연습 모드를 유지하며, LAN 베타에는 두 사람이 각자 맥북에서 참가하는 1대1 경기 루프가 추가되었습니다. 인터넷 매칭/온라인 서버는 없습니다. 실제 두 기기 Wi-Fi 검증은 아직 필요합니다.

## LAN 베타 설치·시작

안정 버전과 다른 응용 프로그램 이름·번들 ID로 설치됩니다.

```sh
brew update
brew install --cask sonsy12/bk/full-court-stickman-lan
```

양쪽 맥북에서 **Full Court Stickman LAN Beta**를 실행하세요. 같은 Wi-Fi 대전 → 방 만들기/방 찾기 → 양쪽 준비 → 방장 시작 순서입니다. 방 검색이 안 되면 방장 화면의 IPv4:포트를 사용합니다. 네트워크 권한/방화벽/게스트망 격리 문제는 주소 입력만으로 해결되지 않습니다.

방장은 오른쪽, 참가자는 왼쪽 골대로 공격합니다. 3분 경기·14초 공격 제한, 득점 후 실점자의 중앙 소유, 리바운드 공격 제한, 종료 전 슛 결과, 동점 선득점 연장과 양쪽 재경기를 포함합니다. Esc/포커스 상실은 전체 일시정지 요청이며 두 사람 준비 후 방장이 재개합니다. 연결 중단은 정지 후 최대 10초 재연결을 기다립니다. 대전에서 R/Tab은 상대 경기 상태를 초기화하지 않습니다.

베타는 자동 업데이트를 중지하고 기존 안정 앱을 유지합니다. 후속 베타를 설치할 때에는 `brew update`와 `brew upgrade --cask sonsy12/bk/full-court-stickman-lan`을 사용하세요. 두 실제 맥북 검증 후 정식 버전으로 승격할 예정입니다.

버전 0.2.0에는 8방향 이동 시 정면·좌우·뒷모습 머리 전환이 추가되었습니다.
대각선 각도는 가까운 방향의 사진을 사용하며 실제 3D 회전은 아닙니다.
점프·점프슛·블로킹 전환은 관절 위치를 보간하며 체공 궤적을 다시 시작하지 않습니다.
Shift 달리기, 0.9초 점프와 부드러운 공중 동작 전환을 포함합니다.

## 설치

GitHub 릴리스와 Homebrew cask가 공개되어 있습니다.

```sh
brew tap sonsy12/bk
brew install --cask full-court-stickman
```

응용 프로그램 폴더의 **Full Court Stickman**을 실행하세요.

## 조작 (LAN 베타5)

아래 새 키 구성은 LAN 베타와 그 안의 연습 모드에 적용됩니다. 별도로 유지되는 안정 앱 v0.4.0의 조작은 바뀌지 않습니다.

| 키 | 동작 |
|---|---|
| 방향키 | 이동; 공 가까이 가면 자동 획득 |
| Shift + 방향키 | 달리기 (이동 속도 1.6배, 모습·애니메이션 동일) |
| Space | 독립 점프 (약 0.9초 유지, 베타3에서 높이 30% 증가) |
| X | 누르면 슛 준비와 게이지가 함께 진행; 초록에서 놓아 슛; 점프 중에는 점프슛 |
| Z | 골대 가까이에서 공을 들고 덩크 |
| C 유지 | 상대를 바라보고 손 올림 수비; 가까운 정면 견제는 슛 초록 구간을 좁힘 |
| B | 손을 뻗는 스틸 시도; 실패하면 짧은 회복과 재사용 대기시간 |
| V | 자동 점프 블로킹; 이미 공중이면 체공 시간을 유지하고 블록 자세로 연결 |
| Esc | 연습: 시작 메뉴 / 대전: 전체 일시정지 요청 |
| Tab | 연습에서만 슛 ↔ 수비 전환 (점수·공 초기화) |
| R | 연습에서만 초기화 |
| Return / ↑↓ | 메뉴 선택·실행; Tab으로 입력칸 이동 |
| Command-Q | 종료 |

공을 소유하면 자동으로 드리블합니다. 득점한 경우에만 공이 가운데로 돌아오며,
실패한 슛은 코트에 남아 다시 잡을 수 있습니다. 조준 화살표와 대상 골대가 초록색이면 링 안쪽을 겨냥한 상태입니다. 이 상태에서 초록 게이지 구간에 맞춰 X를 놓으면 성공 궤적으로 날아갑니다. 조준이 벗어나면 주황색 화살표로 알려줍니다. 거리별 기본 초록 구간은 거리 200 이하 32%, 450에서 16%, 650에서 6%, 750에서 3%, 1000 이상에서 1.5%이며 사이는 연속적으로 좁아집니다. 베타5에서는 이동 중이거나 가까운 정면 수비에 견제받으면 구간이 더 좁아지되, 60Hz 입력으로 맞출 수 있도록 최소 1.5%는 유지합니다. 표시 막대는 슛 준비 동작과 함께 한 번만 진행하며, 0.55초에 중앙, 1.1초에 끝에 도달합니다. 계속 누른다고 다시 초록으로 돌아오지 않습니다. 화면에는 ‘빠름 / 정확 / 늦음’과 ‘노마크 / 약한 견제 / 강한 견제’를 표시합니다. 무작위 실패는 추가하지 않습니다.
슛은 발사 순간 바라보는 방향을 기준으로 날아갑니다. 베타3에서 거리 650까지 조준 보정은 전방 ±22.5도를 유지하며, 거리 1000 이상에서는 ±8도로 줄어듭니다. 사이는 연속적으로 좁아집니다. 초록 조준 화살표는 보정 후 실제 발사 방향을 보여줍니다. 골대를 등지거나 보정 범위를 벗어나면 바라보는 8방향 그대로 쏘며, 발사 후에는 공을 유도하지 않습니다. 타이밍을 놓친 짧은·긴 슛은 그대로 실패 궤적으로 남습니다.
빗나간 공은 바닥에서 감쇠하며 튕긴 뒤 멈추고, 낮게 튀는 동안에도 리바운드로 잡을 수 있습니다.
림과 백보드에는 공의 높이를 포함한 충돌·반사 처리가 적용됩니다. 링 가운데 빈 공간은 충돌 대상이 아닙니다.
v0.3.2부터 일반슛·점프슛은 릴리스 순간 초록 타이밍 성공과 실제 링 하향 통과를 모두 충족해야 득점합니다. 타이밍 결과는 발사 때 고정됩니다. 초록 구간을 벗어난 슛은 림·백보드 반사로 우연히 들어가려 해도 실패로 튕겨 나오며, 중앙으로 초기화하지 않습니다. 초록 타이밍에 성공한 공은 반사 후 실제 링을 통과해도 득점합니다. 가까운 골대를 바라보고 하는 Z 덩크는 게이지 조건에서 제외합니다. 골이 나면 짧은 네트 통과 표시 후 중앙으로 공이 돌아옵니다.
빠른 타이밍은 짧은 슛, 늦은 타이밍은 긴 슛으로 표현합니다. 거리별로 비행 시간이 달라집니다.
X 충전 중에는 이동 속도가 줄어들며 Space로 점프 준비를 연결할 수 있습니다. 점프가 충전 시간이나 체공 시간을 다시 시작하지 않습니다.
배경의 흰 3점선에 맞춘 금색 점선과 같은 경계를 판정에 사용합니다. 두 발이 모두 선 밖이면 3점, 선을 밟거나 안쪽이면 2점입니다. 점프슛은 도약 직전 발 위치를 사용합니다. 실제 경기장 공식 치수가 아닌 이 코트에 맞춘 아케이드 규칙입니다.

## 수비 연습 (LAN 베타5)

Tab으로 전환하면 빨간 졸라맨 상대가 드리블하다가 슛합니다. 상대는 같은 얼굴 자료를 사용하며 몸 색상과 발밑 표시로 구분합니다. 이 모드는 수비 동작을 연습하는 간단한 AI이며 공격·수비를 모두 수행하는 정식 대전 AI는 아닙니다.

C를 누르고 있으면 상대를 바라보고 손을 올립니다. 가까이에서 슛을 실제로 견제하면 블로킹에 실패해도 초록 게이지가 좁아집니다. C 자체는 공을 빼앗지 않습니다. B를 따로 눌러 손을 뻗어야 스틸을 시도하며, 손이 실제 공에 닿아야 성공합니다. 수비 이동은 초당 189 단위, C+Shift 달리기는 302.4 단위로 각각 일반 속도의 90%입니다. 스틸 입력 재사용 대기시간은 0.7초이며 실패 동작에도 짧은 회복 시간이 있습니다. 멀리서 누르거나 공이 손보다 높으면 스틸하지 않습니다.

‘슛 준비’ 표시를 보고 V를 누르면 자동으로 점프 블로킹합니다. Space로 이미 점프한 상태에서 V를 누르면 체공 시간과 도약 위치를 유지하고 블록 자세만 연결합니다. C+Space와 Space+C는 더 이상 블록 입력이 아닙니다. 공과 손의 높이·코트 깊이를 포함한 연속 충돌 검사로 판정합니다. 공이 손보다 높거나 코트 깊이가 다르면 화면에서 겹쳐도 블로킹되지 않습니다. 한 동작에서 한 번만 성공하며 자신의 슛은 블로킹하지 않습니다.

블로킹된 공은 아래·바깥 방향으로 튕긴 뒤 기존 바닥 물리로 이어지고, 중앙으로 초기화되지 않습니다. 낮아진 공은 가까이 있는 플레이어나 상대가 리바운드로 잡습니다. 빼앗은 공으로 기존 X 슛·Z 덩크를 사용할 수 있으며 R로 상대 공격을 다시 시작할 수 있습니다. 상대는 공을 가진 플레이어에게 스틸을 시도하지 않습니다.

내 점수와 상대 점수, 스틸·블록 횟수를 따로 표시합니다. 상대의 슛에도 초록 타이밍과 실제 링 통과 조건을 적용하며 링 통과 전에는 득점하지 않습니다. 블로킹은 해당 슛의 득점 자격을 취소합니다. 초록 구간 밖의 슛은 항상 실패하며, 초록 안의 슛도 실제 하향 링 통과가 있어야 득점합니다. 양발 2/3점 기준은 변경하지 않습니다. 자동 중앙 복귀는 여전히 득점 때만 일어나며 Tab·R은 사용자가 직접 요청하는 연습 초기화입니다.

연습 상대는 1.1초간 준비하고 기본 초록 폭의 35%만큼 중앙에서 벗어난 일정한 타이밍으로 쏩니다. 노마크에서는 초록 안이지만, 충분한 손 올림 견제로 구간을 좁히면 실패합니다. 무작위 성공률을 추가한 것은 아닙니다.

## 슛·수비 설계 방향

NBA 2K 계열의 타이밍 슛과 손 올림 견제·스틸·블록 분리를 참고한 **이 앱만의 키보드 규칙**입니다. 공식 게임의 내부 성공률, 선수 능력치, 아날로그 스틱 리듬 슛을 그대로 재현한 것은 아닙니다. X 한 번의 준비·릴리스로 조작하며, 수비 위치와 실제 손 동작을 기준으로 난이도를 바꿉니다. 거리·이동·견제와 초록 경계를 양쪽 선수에게 같은 규칙으로 적용하고, 최종 판정과 게이지 폭은 방장이 확정합니다.

## 자동 업데이트

아래는 안정 버전에 대한 설명입니다. LAN 베타는 실제 두 기기 검증 전까지 자동 설치를 실행하지 않습니다.

실행 시 GitHub 최신 릴리스를 확인합니다. Homebrew로 설치된 앱이면 새 버전을
Homebrew의 체크섬 검증 경로로 자동 설치합니다. 현재 플레이를 종료시키지는 않으며,
앱을 다시 열면 새 버전이 적용됩니다. 네트워크/업데이트 실패 시 기존 앱은 그대로 사용 가능합니다.
직접 압축 파일을 내려받은 앱은 자동 설치 대상이 아닙니다.

```sh
brew update
brew upgrade --cask sonsy12/bk/full-court-stickman
```

## 개발 및 배포

```sh
bash scripts/build.sh
open "build/Full Court Stickman.app"
```

`dist/Full-Court-Stickman.zip`에 universal 앱이 생성됩니다.
실행 파일은 임시(ad-hoc) 서명이며 Apple 공증은 아직 지원하지 않습니다.
다운로드 앱이 차단되면 시스템 설정 → 개인정보 보호 및 보안의 ‘확인 없이 열기’를 사용하세요.
Gatekeeper를 전체 비활성화할 필요는 없습니다.

다음 릴리스는 Info.plist의 버전을 올리고 빌드한 뒤 GitHub 릴리스에 ZIP을 업로드하고,
Homebrew cask의 버전과 SHA256을 같은 릴리스에 맞춰 갱신해야 합니다.
캐릭터에 사용된 사진의 권리는 원 권리자에게 있으며, 별도의 재배포 허락을 부여하지 않습니다.
